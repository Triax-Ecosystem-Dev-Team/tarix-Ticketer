Tarix Ticketer API Documentation

Complete guide to integrating with the Tarix Ticketer backend services. Base URL: http://localhost:5000/api

Authentication

We use JWT-based authentication. Pass the token in the Authorization header for all private routes.

Authorization: Bearer

Auth Endpoints

POST /auth/register Public

Register a new user account.

Request Body
{
  "name": "Jane Doe",
  "email": "jane@example.com",
  "password": "password123",
  "role": "Admin" // Admin, Ticketer, or Passenger
}
POST /auth/login Public

Login and get an access token.

Request Body
{
  "email": "admin@tarix.com",
  "password": "admin123"
}
Success Response (200)
{
  "success": true,
  "data": {
    "id": "uuid...",
    "token": "jwt_token...",
    "role": "Admin"
  }
}
GET /auth/me Private

Get current user profile and balance.

Trips

GET /trips Public

Search and list available trips.

Query Params
?from=Lagos&to=Abuja&departureDate=2024-05-01
POST /trips Admin Only

Create a new trip schedule.

Request Body
{
  "departureTerminal": "Lagos",
  "arrivalTerminal": "Abuja",
  "departureDate": "2024-05-01",
  "departureTime": "08:00 AM",
  "price": 15000,
  "availableSeats": 30
}
GET /trips/:id Public

Get full details of a specific trip, including assigned bus, driver, and the dynamic busModel containing the seatMatrix layout and basePrice.

Bookings

POST /bookings Private

Create a booking for one or more passengers.

Request Body
{
  "tripId": "uuid...",
  "seats": 2,
  "passengers": [
    { "fullName": "John Doe", "seatNumber": "1A", "phone": "..." },
    { "fullName": "Jane Doe", "seatNumber": "1B", "phone": "..." }
  ],
  "totalPrice": 30000,
  "extraBaggage": 1
}
GET /bookings Private

List current user's bookings (or all bookings if Admin).

Admin Management

POST /admin/ticketers Admin Only

Register a new ticketer with staff profile.

Request Body
{
  "fullName": "Staff Name",
  "email": "staff@tarix.com",
  "password": "...",
  "phone": "...",
  "idNumber": "STAFF001",
  "station": "Lagos",
  "monthlySalary": 50000
}
POST /admin/drivers Admin Only

Register a new driver.

GET /admin/revenue-trend Admin Only

Fetch daily revenue aggregation for the last 7 days.

System Settings

GET /settings Public

Fetch global application settings, including dynamic pricing rules like extraBaggagePrice.

PUT /settings Admin Only

Update global application settings.

Request Body
{
  "extraBaggagePrice": 2500
}

User Profile & Security

PATCH /users/profile Private

Update user personal details like name, phone, and avatar.

Request Body
{
  "name": "Jane Doe",
  "phone": "08012345678",
  "avatar": "https://example.com/avatar.jpg"
}
PATCH /users/security/password Private

Update account password.

Request Body
{
  "currentPassword": "password123",
  "newPassword": "newpassword123"
}
PATCH /users/security/2fa Private

Enable or disable 2FA for the user account.

Request Body
{
  "enabled": true
}
PATCH /users/preferences Private

Update user theme and notification preferences.

Request Body
{
  "theme": "dark",
  "notifEmail": true,
  "notifSms": false,
  "notifPush": true
}

Verification & Testing

System Health Check

Run this script in your terminal to verify all endpoints are working correctly with the database:

cd backend
node test-endpoints.js

Common Fixes

  • CORS Blocked: Ensure your frontend port (e.g., 5173) is in the origin list in server.js.
  • 401 Error: Your JWT token in localStorage might be invalid. Log out and log back in.
  • 500 Error: Check your database connection string in .env.
